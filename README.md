# Gate Check-In Portal

A React web portal for event gate operators to verify families and record check-ins.

## Context

Used for family verification and attendance lookup at events.

## Features

- Operator login with session token
- Event and gate selection (required before check-in)
- Household lookup and family verification
- Check-in page
- Dashboard and audit log pages

## Tech stack

- **Frontend:** React, Vite, React Router
- **Server:** Express static server (Procfile for deployment)

## Getting started

```bash
npm install
cp .env.example .env
npm run dev
# production
npm run build && npm start
```
